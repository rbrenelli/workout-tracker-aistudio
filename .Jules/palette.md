## 2025-03-09 - [Tap Targets for Mobile Accessibility]
**Learning:** The user prefers mobile device settings with very small icons and text. However, interactive UI elements (like the timer, expand buttons, and set/series tracking dots in `ExerciseCard.tsx`) were initially too small (`p-2` or `w-5 h-5`), making them difficult to tap accurately.
**Action:** When designing or refactoring interactive elements, always ensure they maintain a minimum 48x48px tap target (e.g., `w-12 h-12` in Tailwind). If the visual design calls for smaller indicators (like the 20x20px dots), wrap them in a larger invisible `<button>` (using negative margins like `-mx-2` to maintain horizontal compactness without sacrificing the accessible touch area). Add `group` class to the button to style the inner visual element on hover/focus (e.g., `group-hover:border-zinc-400`).
